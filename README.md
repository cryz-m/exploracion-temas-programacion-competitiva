# Exploración de temas

Buenas, lector.

Este repositorio se creó con el fin de compartir códigos y explicaciones que investigo como parte de mi aprendizaje en Programación Competitiva, mejorar en Codeforces y mis actividades en el Club de Programación Competitiva de CENFOTEC. Generalmente, la mejor forma para entender un tema es invertir tiempo en como llegar a esa solución, por eso aunque esto claramente es una guía de como entender el tema, solo debe leerse cuando se está estancado, se ocupa aprender más teoría o definitivamente se ocupa asistencia.
